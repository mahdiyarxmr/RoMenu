# 🥪 بوفه رُکاد (RoMenu) - سامانه جامع سفارش‌گیری و بوفه آنلاین

سامانه جامع بوفه رُکاد با طراحی نئوبروتالیسم مدرن، پیاده‌سازی شده با استک کامل:
**Node.js + NestJS + Next.js 14 (App Router) + React 18 + TypeScript + PostgreSQL + Tailwind CSS**

مطابق با نیازمندی‌های اعلام‌شده در **ROMENU-FEATURES.md** و راهنمای دیزاین سیستم اختصاصی رُکاد **ROKAD_DESIGN_SYSTEM_HANDBOOK (v2.0.0)** با استفاده از فونت‌های رسمی IRANSansX و لوگوتایپ‌های وکتور اختصاصی رُکاد.

## 💎 امکانات و قابلیت‌های پیاده‌سازی شده

### ۱. رابط کاربری سمت مشتری (Mobile-First Experience)
- **قاب اختصاصی موبایل در دسکتاپ**: شبیه‌ساز گوشی با ناچ دوربین، وضعیت باتری، سیگنال و دکمه هوم، سنتر شده با پس‌زمینه شبکه دات ماتریسی. در صفحات موبایل واقعی فول‌اسکرین می‌شود.
- **ویترین بوفه و جستجو**:
  - اسلایدر پیشنهادات ویژه با بج تخفیف و کال‌توبک‌های ترغیب‌کننده.
  - فیلتر سریع بر اساس دسته‌بندی‌ها (نوشیدنی گرم، نوشیدنی سرد، کیک و شیرینی، تنقلات، ساندویچ گرم).
  - جستجوی آنی در میان ۲۰ محصول متنوع با تصویر، قیمت و موجودی انبار.
  - مدیریت کارت محصول با نمایش وضعیت «ناموجود» و کنترل استپری تعداد در سبد خرید.
- **فرمول پرداخت کسری (Fractional Payment Formula)**:
  - `walletUsed = min(walletBalance, total)`
  - `paymentDue = total - walletUsed`
  - در صورت موجودی کافی: پرداخت سریع ۱ کلیکی از کیف پول بدون معطلی و انتقال به درگاه.
  - در صورت کسری موجودی: کسر حداکثر موجودی کیف پول و انتقال مابقی مبلغ به درگاه پرداخت.
- **مدیریت رزرو و تایمر انقضا**:
  - سفارش‌های درگاه دارای رزرو موجودی ۱۵ دقیقه‌ای با تایمر معکوس هستند و در صورت عدم پرداخت آزاد می‌شوند.
- **کیف پول و شارژ آنلاین**:
  - مشاهده لحظه‌ای موجودی و تاریخچه تراکنش‌های تراکنشی کیف پول (Ledger).
  - شارژ با مقادیر سریع (۲۵k، ۵۰k، ۱۰۰k، ۲۰۰k) یا مبلغ دلخواه.
- **درگاه‌های پرداخت چندگانه**:
  - **سندباکس اختصاصی رُکاد (Sandbox)** با قابلیت تست شبیه‌سازی پرداخت موفق، پرداخت ناموفق و انصراف.
  - **درگاه دونیت ریمیت (Reymit)** با تولید کد اختصاصی، کپی اطلاعات و Polling بررسی و تایید آنی وب‌هوک.
  - **درگاه زرین‌پال (ZarinPal REST v4)**.

### ۲. پنل مدیریت بوفه (Admin Dashboard)
- **داشبورد ۶ شاخص کلیدی (KPIs)**:
  - فروش امروز، تعداد سفارش‌ها، مجموع موجودی کاربران در سیستم، کل کاربران، محصولات فعال و کالاهای ناموجود.
- **مدیریت کاربران و تسویه دستی با دلیل اجباری**:
  - لیست کاربران، تغییر وضعیت فعال/غیرفعال.
  - ثبت دستی بستانکاری/بدهکاری به کیف پول کاربر با ثبت اجباری فیلد «علت تراکنش» و درج در لاگ حسابرسی.
- **مدیریت پیشرفته انبار و محصولات (Inventory Movement Ledger)**:
  - تعریف محصول جدید، آپلود تصویر و تغییر قیمت.
  - شارژ انبار (Restock) با ثبت دلیل ورود بار (تامین هفتگی، برگشت از ضایعات، فاکتور خرید).
  - دفتر کل تاریخچه تغییرات موجودی هر کالا با نوع عملیات (`INITIAL`, `RESTOCK`, `RESERVE`, `RELEASE`, `SALE`).
- **مدیریت جامع سفارش‌ها**:
  - فیلتر سفارش‌ها بر اساس ۸ وضعیت: `PENDING_PAYMENT`, `PROCESSING_PAYMENT`, `PAID`, `COMPLETED`, `PAYMENT_FAILED`, `CANCELLED`, `EXPIRED`, `REFUNDED`.
- **گزارش‌های تحلیلی و روزبه‌روز فروش**:
  - تفکیک فروش روزانه، تعداد سفارش‌ها، میانگین ارزش فاکتور (AOV).
  - جدول سهم درصدی فروش هر کالا در روز (Share %).
- **تنظیمات درگاه با رمزنگاری AES-256**:
  - سوییچ بین حالت Sandbox و Live.
  - ذخیره‌سازی کلیدها و توکن‌های درگاه به صورت امن و هش‌شده (با کلید ۳۲ بایتی در بک‌اند).
- **تم‌های دیزاین سیستم رُکاد (Live Theme Switcher)**:
  - پشتیبانی از ۵ تم استایل:
    1. `neo-brutal` (نئوبروتالیسم با بردرهای مشکی و سایه آفست زنده)
    2. `rokad-sticker` (استیکری با پس‌زمینه‌های پترن و برچسب‌های زرد)
    3. `minimal-premium` (مینیمال فاخر با خطوط مویی و سایه‌های نرم)
    4. `dark-neon` (سایبرپانک با رنگ‌های نئونی)
    5. `soft-playful` (شاد و کودکانه با گوشه‌های گرد پاستلی)
  - پشتیبانی از ۵ تم پرسونایی: `ecosystem`, `male`, `female`, `college`, `club`.
  - حالت شب (Dark Mode) کامل.

## 🛠 راه‌اندازی و اجرای محلی

### پیش‌نیازها
- Node.js 18+ و pnpm
- سرویس دیتابیس PostgreSQL (در داکر یا لوکال با دیتابیس `rokad_store`)

### دستورات اجرا

#### بک‌اند (NestJS)
```bash
cd backend
pnpm install
pnpm build
pnpm start:prod # یا node dist/main.js
```

#### فرانت‌اند (Next.js)
```bash
cd frontend
pnpm install
pnpm build
pnpm start # در پورت 3002 اجرا می‌شود
```
